# 补妆镜 APP（手机网页版）

屏幕打光 + 前置摄像头显像的补妆镜。适配安卓和 iPhone。

## 功能
- 屏幕大面积白光打光（色温可调 2500K～7000K：暖白 / 自然光 / 冷白）
- 中央圆形"镜子"显示前置摄像头画面（左右镜像，像照镜子）
- 白光亮度可调
- 镜面大小可调（放大看局部）
- 镜子可开关（纯打光模式）
- 屏幕常亮（防止自动锁屏）
- 点击空白处隐藏 / 显示设置面板

## 怎么用
摄像头调用必须在 **HTTPS** 环境下才能工作（浏览器安全限制）。
所以不能直接双击打开 index.html，需要把整个文件夹部署到一个 HTTPS 网址。任选其一：

### 方法一：GitHub Pages（免费，推荐）
1. 注册 GitHub 账号（github.com）
2. 新建仓库，名字随意，比如 makeup-mirror
3. 把本文件夹里的 5 个文件上传到仓库（网页上直接拖拽上传即可）
   - index.html、manifest.json、icon-192.png、icon-512.png、apple-touch-icon.png
4. 进入仓库 Settings → Pages → Branch 选 main → Save
5. 稍等 1 分钟，会得到一个网址，形如 https://你的用户名.github.io/makeup-mirror/
6. 手机浏览器打开这个网址即可使用

### 方法二：临时本地测试（需电脑）
用 Node.js 的 http-server 或 Python 起本地服务，再手机和电脑连同一 WiFi，用电脑局域网 IP 访问。
注意：本地 http:// 局域网地址，iPhone 的 Safari 会拒绝摄像头，安卓 Chrome 也常拒绝。
最省事还是用方法一。

## 添加到主屏幕（当 APP 用）
- iPhone：Safari 打开网址 → 点底部"分享"按钮 → "添加到主屏幕"
- 安卓：Chrome 打开网址 → 右上角菜单 → "添加到主屏幕"

添加后图标、全屏、无地址栏，体验接近原生 APP。

## 首次使用提示
- 浏览器会弹出摄像头权限请求，请点"允许"
- 如果屏幕还是偏暗，手动把手机亮度调到最高（网页无法控制硬件亮度）
